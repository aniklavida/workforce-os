Run the weekly review. Follow `AGENTS.md`.

Cover:
- Which days hit the target, and which did not
- Which Domains got no attention at all this week
- What finished
- What has been sitting two weeks or more — it needs a date, or it becomes Someday
- Any `Ongoing` item quietly consuming hours

Then help pick **one to three things** for next week. Not more.

Write the full version to the workspace log. Send only the headline in chat.

Ask for any number only the user knows — hours actually worked, for instance. Never estimate it and record it as fact.
